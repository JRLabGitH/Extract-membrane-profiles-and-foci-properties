# 🧬 AP Membrane Intensity Profile Extraction – Midplane Confocal Images

These MATLAB scripts extract and analyse anterior-posterior (AP) membrane intensity profiles from midplane confocal images of the zygote.

The analysis focuses on a 60-pixel-wide stripe encompassing the cell membrane. This stripe is manually drawn around the zygote (starting and ending at the anterior pole in a clockwise direction) and straightened using FIJI's **Straighten** tool.

---

## 🧾 Summary of Scripts

### 📄 `MidplaneCorticalProfExtractor.m`

This script performs the following steps:

1. **Input Selection**
   - Prompts the user to select a folder containing "flatouts" (straightened A-P-A membrane stripes) for one experimental condition.
   - The folder should contain `.tif` images for all imaged channels (e.g., PAR-3, PAR-6, etc.).

2. **Extraction of AP Membrane Intensity Profiles**
   - Extracts membrane intensity profiles normalised against the cytoplasmic background.
   - Splits each profile into left (A→P) and right (P→A) halves.
   - Ensures consistent orientation (Anterior on the left) for all profiles.
   - Saves the resulting AP membrane intensity profiles in data structures (each for a channel): `DC1`, `DC2`, and `DC3` as:
     ```
     [filename, profile]
     ```
     *First rows = left-side profiles; following rows = right-side profiles.*

3. **Alignment and Cropping Around Inflection Point**
   - Fits an error function (erf) to each profile to identify the point of inflection. The point of inflection in the reference channel (typically PAR-3), is set to 0.
   - All profiles are centred and cropped based on this reference inflection point, then profiles are smoothed. These adjusted profiles are the profile_Fix.
   - Data structures `DC1`, `DC2`, `DC3` updated to:
     ```
     [filename, profile, profileFix]
   - Modified profiles are also saved in matrices to be processed by the following function:
     - `ch1M`, `ch2M`, `ch3M` (for individual profiles)
     - `ch1Me`, `ch2Me`, `ch3Me` (averaged left and right profiles per embryo)
  
     ```

---

### 📄 `PlotProfBootstrap.m` (function)

This function extract data to will allow the calculation of profile distances and their error:

4. **Profile Comparison and Bootstrap Analysis**
   - Takes a single matrix (`ch1Me`, `ch2Me`, or `ch3Me`) at a time.
   - Computes mean and standard error of the mean (SEM) for each channel/matrix.
   - Fits an error function (erf) to the AP Mean Intensity Profile (excluding the first and last 40 data points).
   - Sets the point of inflection of the reference channel (PAR-3) to 0, and centres all other channels accordingly.
   - At a given Y-value (intensity level, e.g. Y = 1.8), extracts the corresponding X-position from each channel AP Mean Intensity Profile:
     - These X-positions (xfound) are plotted in the command window and stored in "Table". They will be use to calculate the distance between AP Mean Intensity Profiles.

   - **Bootstrap Analysis**
     - Performs 10,000 random resamplings (bootstraps) from the original profile matrix (`ch1Me`, `ch2Me`, or `ch3Me`).
     - Calculates a Bootstrap AP Mean Intensity Profile and fits an error function (erf)to each bootstrap mean.
     - Calculates 95% confidence intervals (CI) from the bootstrap fitted curves.
     - Extracts the error in X at **Y = 1.8** from the 95% CI envelope.
      - These 95%CI (95CIBootStrp) are plotted in the command window and stored in "Table".

   - **Distance Calculation**
     - The distance between profiles at Y = 1.8, and errors (added in quadrature) are calculated in Excel using xfound and 95CIBootStrp generated by this function.

   - ** Plots**
     - Plots for each channel: the AP Mean Intensity Profile ± SEM, the corresponding fitted curve ± 95% CI, the bootstrap mean curve ± 95% CI.

## 🧪 Requirements

- MATLAB (R2020 or later recommended)
- Image Processing Toolbox
- Flatout `.tif` images straightened in FIJI (ImageJ)
- Excel (for final distance and error computation)

---

## 📁 Example Folder Structure
/ExperimentalCondition_1/
├── embryo1_channel1.tif
├── embryo1_channel2.tif
├── embryo1_channel3.tif
├── embryo2_channel1.tif
└── ...

*Each file should represent a straightened membrane stripe for a specific channel.*

---

## 📝 Notes

- The script assumes flatout images follow the A→P→A orientation.
- The 60-pixel-wide stripe should fully encompass the membrane signal.
- You may need to adapt filenames or the folder parsing logic if your image naming convention differs.
- The error function (erf) is used for both centring and feature extraction due to its robustness in modelling sigmoidal transitions.

---

## 📊 Output Summary

- Raw and adjusted profiles for each embryo and channel
- Profiles centred on a biologically meaningful feature (inflection point)
- Averaged profiles per condition ± SEM
- High-confidence (bootstrap-derived) estimates of distances between different profiles at fixed intensity levels
